# FOLDFLEET

A small 3D paper ocean with a hidden fleet to find. Tap a square to look beneath the water. A hit reveals a folded fragment; follow neighbouring squares to finish the whole boat. Finished boats unfold, rise out of the sea, and automatically mark surrounding known-empty water with a chain of ripples. No timer, opponent attacks, purchases or game-over penalty. Two optional **Ping** hints point to a still-hidden fold. The initial ripple gives a clear first action.

Six finite authored coves use 5×5 or 6×6 charts, 2–4 boats, different shore miniatures and three paper forms: Skiff, Crane and Dragon. Completing the last cove opens a fresh seeded chart series. This reuses six environment kits with newly arranged fleets; it is not an infinite collection of unique scenes. Best results are preserved when replaying. Three stars: finish, stay within the cove's water/miss budget, and use no optional Pings. Six / twelve stars unlock Coral / Gold paper seals. Complete boats add their actual form to a permanent three-entry fleet journal. A repeated hit, cleared water or a finished chart cannot award again.

## Art and feel

Original code-built 3D boats use thin solid paper faces, different front/back/edge colours, crease lines, hinged side folds, raised sails, crane neck/beak/eyes, dragon ridges, small poles and pennants. The chart has a thick enamel/wood base, brass rim and fasteners, shader water and grid, timber pier, paper gull captain, compass and shore props. Reed/petal inlets, a lighthouse, lantern straits and book quays vary the scenery. The opening displays sample boats, separate from the hidden play layout. Phone cinematics use a restrained push; wider views add a short angle reveal. Completed fleets get a brief camera/formation finish. Paper sounds, musical hits, water sounds and the instrumental loop are original local Web Audio synthesis. No generated images, remote fonts, commercial models or third-party audio assets are loaded.

## Actual open-source game foundation

Based on the complete MIT-licensed [Battleship project by Harmeet Matharoo](https://github.com/hmjatt/Battleship), pinned at `f8cd3cfa4d728fbfa0ddb0373fb12f3bc28633b6`. `fleet-source.mjs` ports its `generate`, `revealSquare` and `checkForWins` gameplay into a portable board. Original ship templates execute at runtime from `upstream/ships.js`; the original three JavaScript modules are retained in `upstream/` for provenance. DOM token lists become data cells, width is configurable, generation uses bounded backtracking and no touching hulls, and repeat misses are guarded before counters. The original competitive second board and computer attacks become a cooperative rescue chart. The original image, fonts and sounds are not reused. This is a modified gameplay port, not a claim that the original UI or entire original game runs unchanged.

[Rezona Paper Armada](https://rezona.ai/game/pgcserver/pv/kOlgnleV/v7/dist/index.html) was actually entered and its campaign, fleet selection, click destination, Fire and Pause controls tried. It is a nautical/papercraft presentation reference; damage, a win and its full real-time fleet mechanics were not verified or reproduced. No media/source was copied from it. The licensed source game's own live preview was started, auto-placed and attacked at C3, producing water and a computer turn; no upstream win is claimed. This project's models, interfaces and audio are original.

Full MIT notices for Battleship and Three.js 0.170.0 are in `licenses/` and embedded into both compiled HTML entries. Keep those notices with redistributions. The archived upstream modules may reference their original UI/assets; only `fleet-source.mjs` and the imported ship-template module form this application's runtime dependency.

## Run, build, package

`index.html` and `standalone.html` are byte-identical, self-contained builds. The ZIP contains a root `index.html`, editable modules, the vendor, icon, cover and notices. No CDN, login, SDK or external media fetch is needed for startup. Serve the directory over HTTP/HTTPS for browser play or import the root-index ZIP into a compatible HTML5 host. `index-source.html` is the editable development entry.

Rebuild with Python 3 and the official esbuild 0.25.0 executable: set `ESBUILD` to its executable path and run `python build.py`. The development workspace has a local fallback path; that executable is intentionally not shipped in the game. Run `node core-tests.mjs` and `node sdk-tests.mjs` for actual placement/hit/win, checkpoint/progression, remix and SDK mock checks. The small runtime script is also emitted as `game.js`, but the compiled entries embed it rather than fetching it.

## Saves and GameWave

Only `foldfleet.profile.v1` is accessed locally. The own profile includes best stars, active level/remix/committed taps/Ping use, found paper forms, sound, seal, selected cove and separate durable like/comment flags. A checkpoint is reconstructed through the actual rules, retaining found ships and automatically cleared water while rejecting invalid or duplicate tap histories. Incomplete charts resume; a finished chart awards immediately once and saves `active:null`.

GameWave uses the raw JavaScript envelope `{game:'foldfleet',v:1,profile:...}`. Own best stars and journal entries merge without dropping local preferences/current play. Foreign cloud envelopes are not overwritten. A valid square search or committed Ping starts a host session; the first valid action after restoring a visit also starts that new session. Completing the actual fleet ends once. Pause/result viewing/rewards do not start or end a round; explicitly restarting/changing a committed incomplete chart closes that attempt. Optional SDK discovery and async registration never gate standalone startup.

Positive direct like callbacks unlock the Gold seal; successful direct comment callbacks, including empty image-only comments, unlock Coral. Unlike gives nothing; callback fields are direct and `project_id` stays a string. `count` is not event identity. Explicit saved flags prevent re-awards within the available save scope. Both are also earned by normal stars, remain optional and only appear as host offers after registration succeeds. Local-only claims are device/browser scoped. Cleanup, late registration, failed methods, asynchronous errors and missing/partial/late SDK are guarded. Official November 24 SDK documentation was rechecked November 27. Mock SDK testing is not real GameWave App certification.

## Evidence limits

Tests include generated fleet separation/bounds, actual hit/win counters and auto-water safety, full source-rule solutions across six coves and seeded remixes, repeated actions, checkpoint reconstruction, real-action-coupled SDK mocks and adapter failures/cleanup. Browser completion tests use authored solutions through normal controls; they are software checks rather than a claim about an unaided player's difficulty. Device-size touch/layout tests do not establish performance on physical phones. Actual supported GameWave import/callback operation remains to be tested in that host. Browser-tool file URL restrictions prevent claiming a directly tested offline-file launch; the self-contained archive and matching web entries are verified separately. No unrelated legacy game is modified or certified.
